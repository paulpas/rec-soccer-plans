5:45 – 6:00 PM
Play 1: Goal Kick Quick Combo
0/9

The quick combo: defender kicks it out to the left wing, the wing carries it up the line, a quick pass across to the front center, a give-and-go to the right wing, and a shot. Watch the step-by-step diagrams below.

Starting shape

● CR● LW● FC● RW→ pass / run

Step 1

● CR● LW● FC● RW→ pass / run
1. Center rear kicks the ball out to the left wing.

Step 2

● CR● LW● FC● RW→ pass / run
2. Left wing dribbles up the side. Everyone else runs up the field.

Step 3

● CR● LW● FC● RW→ pass / run
3. Left wing passes across to front center.

Step 4

● CR● LW● FC● RW→ pass / run
4. Front center passes to the right wing. Left wing and center rear follow up.

Step 5

● CR● LW● FC● RW→ pass / run
5. Right wing shoots. GOAL! Front center and left wing crash the box for rebounds.
6:00 – 6:15 PM
Play 2: Build-Up Passing Sequence
0/9

The longer buildup: kick it out, play inside, play it back to the wing running past, feed the center at the line, move it to the right wing, lay it up the line, control to the center, and finish. One pass / one run per step.

Starting shape

● CR● LW● FC● RW→ pass / run

Step 1

● CR● LW● FC● RW→ pass / run
1. Center rear kicks the ball out to the left wing.

Step 2

● CR● LW● FC● RW→ pass / run
2. Left wing passes inside to front center. Right wing moves up.

Step 3

● CR● LW● FC● RW→ pass / run
3. Front center plays it back to the left wing, who runs up the side.

Step 4

● CR● LW● FC● RW→ pass / run
4. Left wing passes in to front center at halfway.

Step 5

● CR● LW● FC● RW→ pass / run
5. Front center passes to the right wing.

Step 6

● CR● LW● FC● RW→ pass / run
6. Right wing sends it up the line to the left wing. Others move into the box.

Step 7

● CR● LW● FC● RW→ pass / run
7. Left wing passes inside to front center.

Step 8

● CR● LW● FC● RW→ pass / run
8. Front center shoots. GOAL!
6:15 – 6:30 PM
Play-Out Game
0/4

2 small goals across a half-field. Split into two teams. When your team has the ball, you must complete the full play-out sequence (CR → LW → FC → RW) before you're allowed to shoot. If the other team wins the ball they attack immediately. Completed sequences = bonus point. This makes running the play a real game reward.
